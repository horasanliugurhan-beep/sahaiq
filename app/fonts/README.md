# Archivo

Mevcut demo yazı tipi, Google Fonts isteği yerine yerel dosyadan sunulur.
Yeni npm bağımlılığı yoktur. Değişken fontun ağırlık ve genişlik eksenleri korunur.

- Kaynak: https://github.com/google/fonts/tree/main/ofl/archivo
- Dosya: `Archivo[wdth,wght].ttf` → `Archivo.ttf`
- Lisans: [SIL Open Font License 1.1](OFL.txt)
- `next/font/local` dosyayı derlemenin içine alır; alt dizindeki statik yayında da font yolu Next.js tarafından üretilir.
